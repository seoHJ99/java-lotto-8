# 로또 발매기

## 목적
로또 자동 발행 프로그램.
사용자가 입력한 구입액만큼 로또를 발행하고, 당첨번호를 입력받아 최종 결과와 수익률을 출력한다.

## 조건
- 로또 범위는 1~45사이다.
- 한번에 6개 숫자와 1개의 보너스 숫자를 뽑는다. 숫자는 중복되지 않는다.
- 로또 구입 금액을 입력하면 그에 해당하는 개수만큼 로또를 발행한다.
- 로또 하나에 1000원이다.
- 1000원 단위로 나눠떨어지지 않는 경우는 예외 처리한다.
- 사용자로부터 당첨번호 6개와 보너스 번호 1개를 입력받아, 당첨 내역을 구한다.
- 로또 당첨되기 위해서 순서까지 일치할 필요는 없다.
- 총 수익율은 소수점 둘째자리에서 반올림하여 보여준다.
- 로또 번호는 오름차순으로 보여준다.
- 사용자로부터 잘못된 값을 입력받으면 IllegalArgumentException 를 발생시키고 [ERROR] 로 시작하는 메세지를 출력한다.
- [ERROR] 메세지 출력 이후부터 다시 입력받는다. 프로그램은 멈추지 않는다.
- 당첨 금액과 기준은 아래 표와 같다.

| 등수 | 당첨 조건 | 당첨금 |
|:----:|:--------------------------|----------------:|
| 1등 | 6개 번호 일치 | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 |
| 3등 | 5개 번호 일치 | 1,500,000원 |
| 4등 | 4개 번호 일치 | 50,000원 |
| 5등 | 3개 번호 일치 | 5,000원 |

## 프로그래밍 요구사항
- 메서드 길이는 15줄 이내로 한정한다.
- else를 사용하지 않는다.
- Enum 을 사용한다.
- 출력문을 제외하고 단위테스트를 작성한다.
- Lotto 클래스를 이용해서 구현한다. 필드를 추가할수 없다.

## 고려사항
- 유지 보수를 신경쓰며 도메인, 서비스, 인프라로 구조를 나눠 개발한다. 
- view 단은 최대한 독립되어 관리하기 위해 입력값 검증은 도메인 생성자 함수에서 수행한다.
    - 단, 입력값 형식 검사는 view 단에서 수행함

## 주요 기능
- 로또 번호 생성
- 당첨번호 생성
- 당첨번호 추가 번호 생성
- 사용자 입력값 받아서 로또 발행
- 당첨번호 비교하여 당첨 등수 계산
- 당첨 등수에 따른 수익금 계산

## 예외 상황
- 1000원 단위로 나눠떨어지지 않는 금액을 입력한다.
- 숫자가 아닌 값을 입력한다.
- 당첨번호를 1~45 이외의 문자를 입력한다.
- 빈 값을 입력한다.
- 2^31 (2,147,483,647) 이상의 숫자를 입력한다.
- 입력한 당첨 숫자가 6자리가 아니다.

## 고려사항
Lotto 클래스를 지침으로 생각한다. 따라서 검증 로직은 생성자 함수에서 처리한다. 당첨 숫자 클래스 WinNumbers 의 필드값, 당첨숫자와 보너스 숫자를 한번에 생성자 함수를 받지 않고, 각각 따로 받도록 정한다.
이를 위해 setter 함수를 사용한다.<br>
Lotto 클래스는 추가할지언정 수정하지는 않는다.
구매 금액을 따로 도메인으로 생성하지 않고 숫자로만 입력받고자 했다. 그러나 이경우 유효성 검증이 view나 service 단에서 이뤄진다.
따라서 구매금액 도메인 클래스 역시 새롭게 생성하기로 한다.
